# Análisis de viabilidad

## Viabilidad técnica

### Ventajas

- El problema esta claramente delimitado.
- Existe Arquitectura Candidata y modelo de datos base.
- La implementación futura puede abordarse de forma modular.

### Riesgos

- Requerirá disciplina para mantener integridad entre ventas e inventario.
- La futura eleccion de tecnologia debera alinearse con el tamano real del negocio.

### Observaciones

La viabilidad técnica es favorable porque el sistema propuesto no requiere complejidad extrema para iniciar.

### Conclusión

La iniciativa es técnicamente viable como proyecto incremental de pequeña y mediana escala.

## Viabilidad operativa

### Ventajas

- El sistema responde a procesos cotidianos del negocio.
- Los mockups y Casos de Uso ya muestran una operación comprensible.

### Riesgos

- Posible resistencia inicial al cambio.
- Necesidad de capacitación para adopción adecuada.

### Observaciones

La operación del negocio puede adaptarse al sistema si se prioriza simplicidad de uso.

### Conclusión

La viabilidad operativa es alta, siempre que se acompañe de capacitación y seguimiento.

## Viabilidad economica

### Ventajas

- El sistema puede plantearse por etapas.
- La inversion puede concentrarse primero en funciones críticas.

### Riesgos

- El negocio podria requerir priorizacion cuidadosa de recursos.
- Una implementación demasiado ambiciosa desde el inicio podria elevar costos innecesarios.

### Observaciones

Una estrategia modular reduce el costo inicial y mejora retorno esperado.

### Conclusión

La viabilidad economica es razonable si se implementa por fases y con enfoque pragmático.

## Viabilidad organizacional

### Ventajas

- El negocio tiene un responsable principal claro.
- La necesidad de control administrativo es evidente.

### Riesgos

- La dependencia de procesos manuales actuales puede dificultar adopción inicial.

### Observaciones

El cambio organizacional es manejable en un negocio pequeño si se comunica el beneficio operativo.

### Conclusión

La viabilidad organizacional es favorable con acompanamiento y claridad de roles.

## Viabilidad legal

### Ventajas

- La fase actual no compromete aún una solución regulatoria cerrada.
- Permite considerar normativas futuras antes de implementar.

### Riesgos

- Una implementación real debera revisar temas fiscales, respaldo y control de información.

### Observaciones

La propuesta es legalmente viable a nivel conceptual, pero requerirá revision local antes de desarrollo real.

### Conclusión

La viabilidad legal es positiva en fase documental y condicionada en fase de implementación.

## Viabilidad temporal

### Ventajas

- El proyecto ya cuenta con base documental madura.
- La implementación podria iniciar sobre componentes ya definidos.

### Riesgos

- Un alcance mal controlado podria extender tiempos.

### Observaciones

La existencia de análisis, arquitectura, mockups y QA reduce tiempo de arranque futuro.

### Conclusión

La viabilidad temporal es adecuada si se controla alcance y se respeta un roadmap incremental.
