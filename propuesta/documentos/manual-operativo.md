# Manual operativo conceptual

## Objetivo

Explicar de forma conceptual como se utilizaria el sistema en una implementación futura, concentrandose en flujos operativos y responsabilidades del negocio.

## Flujo general de uso

1. El usuario inicia sesión.
2. Ingresa al módulo correspondiente segun su rol.
3. Consulta catalogos, registra ventas o compras, o revisa reportes.
4. El sistema valida reglas de negocio y actualiza la información.
5. El administrador revisa cierres y reportes.

## Procesos principales

### Ventas

- buscar producto;
- validar stock;
- registrar cantidades;
- calcular total;
- confirmar venta;
- actualizar inventario.

### Inventario

- consultar existencias;
- revisar alertas;
- registrar ajustes;
- detectar productos vencidos o agotados.

### Compras

- seleccionar proveedor;
- registrar productos comprados;
- confirmar ingreso;
- reflejar aumento de stock.

### Reportes

- consultar ventas por fecha;
- revisar productos agotados;
- revisar rotación y resumen del negocio.

### Cierre diario

- revisar total vendido;
- validar número de transacciones;
- registrar observaciones;
- consolidar el cierre de jornada.

## Responsabilidades

- **Administrador:** supervisa catalogos, reportes y cierres.
- **Empleado:** registra ventas y consulta información operativa.
- **Don Pedro:** utiliza la información para control y decisiones del negocio.

## Observacion final

Este manual es conceptual y sirve como apoyo de adopción. No reemplaza un manual técnico ni una guia de una implementación real.
