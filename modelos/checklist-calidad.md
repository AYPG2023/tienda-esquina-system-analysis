# Checklist de calidad

| Elemento | Estado | Observacion |
|---|---|---|
| Consistencia documental general | Conforme | Los documentos principales mantienen una misma linea narrativa y funcional |
| Coherencia entre diagramas | Conforme | Los diagramas reutilizan actores, módulos y entidades consistentes |
| Alineacion Scrum | Conforme | Backlog, sprints, refinement, DoR y DoD están documentados |
| Alineacion RF/RNF | Conforme | Requerimientos funcionales y no funcionales tienen continuidad en arquitectura y mockups |
| Trazabilidad RF-HU-CU | Conforme | Existe matriz de trazabilidad y matriz de validación |
| Calidad visual de mockups | Conforme | Las pantallas comparten estilo, navegación y jerarquía visual |
| Ortografia y redaccion | Conforme con observacion | El contenido es formal; conviene una revision final de acentos si se exporta |
| Completitud del proyecto | Conforme | Se cubren análisis, modelado, arquitectura, mockups, riesgos y QA |
| Organización de carpetas | Conforme | La estructura separa docs, modelos, diagramas y mockups |
| Nombres de archivos | Conforme | La nomenclatura es ordenada y secuencial |
| Enlaces y referencias internas | Conforme | Las referencias principales entre archivos y pantallas están presentes |
| Preparación para entrega académica | Conforme | El repositorio esta listo para revision final y exportacion |
