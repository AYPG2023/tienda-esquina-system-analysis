Resultado final

Conclusiones del proyecto

El proyecto demuestra que una necesidad operativa pequeña puede convertirse en una solución documental robusta cuando existe disciplina de ingeniería de software, trazabilidad y criterio de negocio.

Lectura técnica

La coherencia entre RF, RNF, historias, Casos de Uso, modelo ER, arquitectura y mockups deja una base útil para una futura construcción incremental del sistema.

Lectura organizacional

El sistema propuesto impactaria directamente el orden administrativo de Don Pedro: menos errores, mejor control de inventario, cierres diarios más confiables y mejor información para decidir.

Conclusión general

Tienda de la Esquina queda consolidado como un proyecto académico sólido, con perfil de consultoría y con una estructura apta para revisión docente, conversión a PDF y posible evolución hacia una implementación real.
